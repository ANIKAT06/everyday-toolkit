# Contributing

Thanks for helping make Everyday Toolkit more useful and welcoming.

## Ways to help

- Report a reproducible bug or suggest a focused everyday tool.
- Improve keyboard access, screen-reader support, contrast, mobile layout, or translations.
- Fix a bug or improve a tool while keeping the interface simple.

## Before you open a pull request

1. For a substantial feature, open an issue first so we can agree on its scope.
2. Keep the app dependency-free and usable as static files on GitHub Pages.
3. Keep user inputs on-device. Do not add analytics, remote processing, advertising, or third-party runtime calls.
4. Use semantic HTML, labels, visible focus indicators, and clear feedback for errors.
5. Test the changed tool in a modern browser at desktop and narrow mobile widths. For service-worker changes, test on `localhost` or HTTPS.
6. Describe what changed and how you tested it in your pull request.
